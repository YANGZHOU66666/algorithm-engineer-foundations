# 状态转移型期望的计算

题目特点：算一定条件下的期望，能够定义出状态

思路：定义状态和状态间的转移概率。某状态到终态的期望 = 转移成本 + 后面的状态到终态的期望在转移概率上的加权和



**例1: 抛硬币，直到连续两次正面后停，问抛硬币次数的期望**

定义几个状态：

$S_0$ - 0次连续正面；$S_1$ - 1次连续正面；$S_2$ - 2次连续正面（终态）
设从三者到终态的次数期望分别为$E_0$、$E_1$、$E_2$

那么，$S_0$有0.5概率转化为$S_0$、0.5概率转化为$S_1$；$S_1$有0.5概率转化为$S_0$、0.5概率转化为$S_2$

$E_0 = 1 + 0.5*E_0 + 0.5*E_1$：从$S_0$要抛的次数，就等于先抛一次然后0.5概率还要从$S_0$抛、0.5概率从$S_1$抛。

$E_1 = 1 + 0.5*E_0+0.5*E_2$（同理）

$E_2 = 0$



**例2: 干脆面中有均等的概率抽到108将的卡。问集齐108将的期望抽卡数**

定义$E_k$为手上有k张卡的还需要抽的次数的期望，那么

$$E_k = 1 + \frac{108-k}{108} E_{k+1} + \frac{k}{108} E_k$$

然后，$E_{108}=0$，我们要求$E_0$。
