# Ragas指标

## Context Precision

核心：我们检索回来的这些信息片段，到底有多少是真正和用户问题相关的？

计算思路：

对N个（有优先级顺序的）召回的文本块，k从1到N遍历，分别计算precision@k，然后求N个precision@k的和

$precision@k$定义：$precision@k=\frac{前k个文本块里需要用于生成回答的数量}{k}$

$Context\ Precision=\frac{1}{N}\sum_{k=1}^Nprecision@k$



## Faithfulness

核心：检查答案中的每一句话、每一个事实点，是否都能在提供的上下文中找到依据

计算思路：

1. 提取回答中的所有最简单的主张（Claim）

**示例：**

原始答案: "爱因斯坦于1879年3月14日出生在德国，他是一位理论物理学家。"

LLM 拆解后的主张:

- "爱因斯坦于1879年3月14日出生。"
- "爱因斯坦出生在德国。"
- "爱因斯坦是一位理论物理学家。"

2. 验证每个主张是不是都能通过检索到的文本回答
