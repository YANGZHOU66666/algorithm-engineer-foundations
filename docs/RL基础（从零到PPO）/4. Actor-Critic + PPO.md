# 4. Actor-Critic + PPO

## Actor-Critic

一类方法的统称，根本上还是优化策略，但是额外维护一个价值估计critic模型来辅助优化策略。

整体框架：每轮进行 策略网络采样->用TD Target优化状态价值模型->用状态价值的估计来作为优势函数，优化策略模型。

更新Critic价值网络参数的方法类似DQN，还是用TD target来拟合当前状态价值，损失函数$$\mathcal{L}(\omega) = \frac{1}{2} (r + \gamma V_\omega(s_{t+1}) - V_\omega(s_t))^2$$，梯度下降更新参数。可以加上目标网络的思路，提高训练过程稳定性。

更新策略网络参数的方法，复用$$\nabla_\theta J(\theta) = \mathbb{E} \left[ \sum_{t=0}^T \psi_t \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right]$$模式，把$\psi_t$换成价值网络的动作价值估计$$\psi_t = r_t + \gamma V^\pi(s_{t+1}) - V^\pi(s_t)$$，然后反向传播更新。

总结下Actor-Critic整体框架：

* 初始化策略网络参数 $\theta$，价值网络参数 $\omega$
* **for** 序列 $e = 1 \to E$ **do** :
  * 用当前策略 $\pi_\theta$ 采样轨迹 $\{s_1, a_1, r_1, s_2, a_2, r_2, \dots\}$
  * 为每一步数据计算：$\delta_t = r_t + \gamma V_\omega(s_{t+1}) - V_\omega(s_t)$
  * 更新价值参数 $w = w + \alpha_\omega \sum_t \delta_t \nabla_\omega V_\omega(s_t)$
  * 更新策略参数 $\theta = \theta + \alpha_\theta \sum_t \delta_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)$
* **end for**

## PPO (Proximal Policy Optimization)

### 重要性采样原理

对于黑盒函数f(x)，如果我们希望估计它在Q(x)（这个分布已知）上的期望，但只有$P(x)$（这个分布已知）上的若干采样。希望用这个采样，不重新在$Q(x)$上采样来直接估计

$$\mathbb{E}_{x \sim P}[f(x)] = \int f(x) P(x) \, dx = \int f(x) \cdot \frac{P(x)}{Q(x)} \cdot Q(x) \, dx = \int \left( f(x) \frac{P(x)}{Q(x)} \right) Q(x) \, dx$$

$$\mathbb{E}_{x \sim P}[f(x)] = \mathbb{E}_{x \sim Q} \left[ f(x) \frac{P(x)}{Q(x)} \right]$$

也就是说，$f(x)$在$P(x)$上的采样，等于$f(x)\frac{P(x)}{Q(x)}$在Q(x)上的采样。对于我们每个采样好的样本点$f(x_i)$，只要转化为$f(x_i)\frac{P(x_i)}{Q(x_i)}$，就能近似估计为在Q(x)上采样的点

### GAE(Generalized Advantage Estimation, 广义优势估计)优势函数

直观理解：多步TD Error的指数加权平均。通过$\lambda$来调整多步数TD Error的权重，来控制偏差和方差。

单步的TD Error：

$$\delta_t^V = r_t + \gamma V(s_{t+1}) - V(s_t)$$

类似Sarsa和多步Sarsa的单步/多步TD Target估计，我们也可以定义看单步/多步的优势值。先算出用n步估计的$Q(s_t,a_t)$，然后减去$V(s_t)$

单步优势：$A_t^{(1)} = r_t + \gamma V(s_{t+1})-V(s_t)$

两步优势：$A_t^{(2)}=r_t+\gamma r_{t+1}+\gamma^2 V(s_{t+2})-V(s_t)$

n步优势：$A_t^{(n)}=r_t+\gamma r_{t+1}+\gamma^2 r_{t+2}+\dots+\gamma^{n-1} r_{t+n-1}+\gamma^n V(s_{t+n})-V(s_t)$

这里我们不知道看几步是最能兼顾方差和偏差的，所以我们决定“都看”。

定义$A^{GAE}_t=(1-\lambda)(A_t^{(1)}+\lambda A_t^{(2)}+\lambda^2 A_t^{(3)}+\dots)$

这里前面要乘以$(1-\lambda)$，是保证所有加权系数和为1

把右式中$A_t^{(k)}$一个个展开，可以得出$$\hat{A}_t^{\text{GAE}} = \sum_{l=0}^\infty (\gamma \lambda)^l \delta_{t+l}^V$$

### PPO两种写法

**PPO-KL惩罚**：在目标函数中减去KL散度，最大化目标函数时要保证KL比较小

$$\mathcal{L}^{\text{KLPEN}}(\theta) = \hat{\mathbb{E}}_t \left[ \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)} \hat{A}_t - \beta \cdot D_{\text{KL}}\Big(\pi_{\theta_{\text{old}}}(\cdot \mid s_t) \,\parallel\, \pi_\theta(\cdot \mid s_t)\Big) \right]$$

**PPO-clip截断**：在目标函数中加上clip机制，保证重要性采样比例不偏离1太远

$$\mathcal{L}^{\text{CLIP}}(\theta) = \hat{\mathbb{E}}_t \left[ \min\left( \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)} \hat{A}_t, \; \text{clip}\left(\frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)}, \, 1-\epsilon, \, 1+\epsilon\right) \hat{A}_t \right) \right]$$

### PPO训练流程

进行如下循环：

1. 用当前策略采样若干轨迹
2. 用critic网络算出轨迹上所有状态的$V(s_t)$
3. 算出所有状态上的$A^{GAE}_t$、状态价值估计$A^{GAE}_t+V(s_t)$
4. 采样mini-batch，对目标函数梯度下降来优化策略网络；反向传播优化critic网络
5. 继续循环
