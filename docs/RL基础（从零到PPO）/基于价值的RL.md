# 基于价值的RL

核心思路：给所有状态-动作对打分，产物只有一个得分的地图，策略是隐式的，参考地图上的价值来定策略

## RL 基础

基本概念：马尔可夫过程$M = (S, A, P, R, \gamma)$

- 智能体，Agent：学习者和决策者
- 环境，Environment：智能体所处的外部世界，智能体可以与之交互
- 状态，state，s：智能体当前所处环境的描述
- 动作，action，a：智能体在某个状态下可以执行的动作，可以到另一状态
- 策略，policy，$\pi$：智能体根据当前state，选择每个action的概率分布的集合
- 奖励，reward，r：从某state到另一state获得的即时反馈
- Q值，Q-value，Q(s,a)：它表示智能体在状态 s 下，执行动作 a 后，并且之后一直遵循最优策略所能获得的**期望累积奖励**。Q值越高，说明在当前状态下执行该动作越好。

## Monte Carlo

思想：根据采样的**整条路经**，更新Q表和策略

整个过程：

1. 收集路径（包括经过的每个状态、状态转移的动作、每个状态转移获得的reward）
2. 计算路径中每个经过(s,a)的回报（从这之后各奖励的结合折扣因子加权和），以此更新Q(s,a)值
3. 根据Q(s,a)值更新策略
4. 在新的策略上继续收集数据，重复上述过程



### 具体流程

1. 收集路径

记下每条路径经过的每个状态、状态转移的动作、每个状态转移获得的reward

- 例如：

$S_{1}-(经过a_1获得+5)->S_2-(经过a_2获得-3)->S_3-(经过a_3获得+4)->S_4$

2. 计算回报并更新Q表

回报$return = reward_1+\lambda reward_2+\lambda^2reward_3+...$

- 例如：

假设折扣因子$\lambda=0.9$，学习率$\alpha=0.5$

对$(S_1,a_1)$的$return_1$：$(+5)+0.9*(-3)+0.9^2*4=5.54$

对$(S_2,a_2)$的$return_2$：$-3+0.9*4=0.6$

对$(S_3,a_3)$的$return_3$：$4$

使用增量更新更新Q表：

$Q(S_1,a_1)=Q(S_1,a_1)+\alpha(return_1-Q(S_1,a_1))=2.77$

$Q(S_2,a_2)=Q(S_2,a_2)+\alpha(return_2-Q(S_2,a_2)) = 0.3$

$Q(S_3,a_3)=Q(S_3,a_3)+\alpha(return_3-Q(S_3,a_3)) = 2$

3. 根据Q表更新策略：

假设采取绝对贪婪的策略，那么就是每个状态下，策略是选Q值最大的动作

4. 策略更新后，根据新的策略继续执行一些例子，收集路径，重复1-3过程



### 可选的不同种类替代

以上是一个蒙特卡洛算法的基本框架，细分下还有不同种类之分：

#### 首次访问蒙特卡洛 vs 每次访问蒙特卡洛

在**计算回报并更新Q表**的流程中，

首次访问：若一条路径多次经过同一个(s,a)，只对经过第一次时更新Q(s,a)

每次访问：每次经过都更新



#### 蒙特卡洛控制：探索（exploration）vs 利用（exploitation）

在**”根据Q表更新策略“**流程中，

绝对贪婪策略：policy为，对每个状态s，以100%概率选择Q值最大的动作

$\epsilon-greedy$策略：policy为，对每个状态s，以$1-\epsilon$概率选择Q值最大的动作，$\epsilon$概率随机选择一个动作（包括那个Q值最大的）



### 补充：蒙特卡洛控制 vs 蒙特卡洛评估

**”蒙特卡洛评估“**：对某已知策略$\pi$生成的已有的路径，使用蒙特卡洛方法来学习，得到一系列Q和V值，目标是看待评估的那个$\pi$各方面（比如Q值、V值）是什么情况

**”蒙特卡洛控制“**：如上面演示的流程，目标是学习一个趋于最优的策略，我一直”评估“我自己现在的策略，并根据Q值改变策略，超越我自己



### 蒙特卡洛算法完整示例：网格世界

#### 环境设置

4×4网格世界

```
+---+---+---+---+
| S |   |   | G |  
+---+---+---+---+
|   | X |   |   |
+---+---+---+---+
|   |   |   |   |
+---+---+---+---+
|   |   |   |   |
+---+---+---+---+
```

- S: 起始位置 (0,0)
- G: 目标位置 (0,3)，奖励 +10
- X: 陷阱位置 (1,1)，奖励 -10
- 其他位置：奖励 -1
- 动作：上、下、左、右
- 折扣因子 γ = 0.9



#### 第1轮：首次访问蒙特卡洛策略评估

初始设置：

```
策略π（随机策略）：每个状态下4个动作等概率 (0.25, 0.25, 0.25, 0.25)
Q表初始化：Q(s,a) = 0 for all s,a
访问计数：Returns(s,a) = [] for all s,a
```

回合1：生成轨迹：

```
回合轨迹：
t=0: S(0,0) → 动作:右 → 奖励:-1 → S'(0,1)
t=1: S(0,1) → 动作:右 → 奖励:-1 → S'(0,2)  
t=2: S(0,2) → 动作:右 → 奖励:+10 → S'(0,3) [终止]

轨迹：[(0,0),右,-1] → [(0,1),右,-1] → [(0,2),右,+10]
```

计算累积回报：

```
从t=0开始：G₀ = -1 + 0.9×(-1) + 0.9²×10 = -1 - 0.9 + 8.1 = 6.2
从t=1开始：G₁ = -1 + 0.9×10 = -1 + 9 = 8.0  
从t=2开始：G₂ = 10
```

更新Q函数（首次访问）：

```
Q((0,0), 右) ← 6.2  [首次访问]
Q((0,1), 右) ← 8.0  [首次访问]  
Q((0,2), 右) ← 10.0 [首次访问]

其他Q值保持为0
```

回合2：另一个轨迹

```
轨迹：
t=0: S(0,0) → 动作:下 → 奖励:-1 → S'(1,0)
t=1: S(1,0) → 动作:右 → 奖励:-1 → S'(1,1) [陷阱]
t=2: S(1,1) → 奖励:-10 → 回合结束

累积回报：
G₀ = -1 + 0.9×(-1) + 0.9²×(-10) = -1 - 0.9 - 8.1 = -10.0
G₁ = -1 + 0.9×(-10) = -1 - 9 = -10.0
G₂ = -10.0
```

更新Q函数

```
Q((0,0), 下) ← -10.0
Q((1,0), 右) ← -10.0  
Q((1,1), 停止) ← -10.0

当前Q表状态：
Q((0,0), 右) = 6.2
Q((0,0), 下) = -10.0
Q((0,1), 右) = 8.0
Q((0,2), 右) = 10.0
其他值为0
```

#### 第2轮：策略改进

基于Q函数改进策略

```
对于状态(0,0)：
- Q((0,0), 上) = 0
- Q((0,0), 下) = -10.0  
- Q((0,0), 左) = 0
- Q((0,0), 右) = 6.2   ← 最大值

新策略：π'((0,0)) = 右 (或ε-贪婪策略)
```

ε-贪婪策略更新

```
假设ε = 0.1：
π'(右|(0,0)) = 1 - 0.1 + 0.1/4 = 0.925
π'(其他动作|(0,0)) = 0.1/4 = 0.025

对于状态(0,1)：
最佳动作是"右"（Q=8.0），其他为0
π'(右|(0,1)) = 0.925
π'(其他|(0,1)) = 0.025
```

#### 第3轮：继续蒙特卡洛控制

用新策略生成回合

```
回合3（使用改进后的策略）：
t=0: S(0,0) → 动作:右[0.925概率] → 奖励:-1 → S'(0,1)
t=1: S(0,1) → 动作:右[0.925概率] → 奖励:-1 → S'(0,2)
t=2: S(0,2) → 动作:右[随机选择] → 奖励:+10 → S'(0,3)

这条路径更可能被选择，因为策略已经学会了好的路径
```

增量式更新

```
使用增量公式更新Q值：
Q(s,a) ← Q(s,a) + α[G - Q(s,a)]

假设α = 0.1，G₀ = 6.2（相同路径）：
Q((0,0), 右) ← 6.2 + 0.1[6.2 - 6.2] = 6.2

如果是新的回报G₀ = 5.8：
Q((0,0), 右) ← 6.2 + 0.1[5.8 - 6.2] = 6.2 - 0.04 = 6.16
```

#### 多轮迭代后的Q表

```
经过1000个回合后：
+-------+-------+-------+-------+
| Q值   | (0,0) | (0,1) | (0,2) | (0,3)
+-------+-------+-------+-------+
| 上    |  2.1  |  4.5  |  7.2  |  0.0
| 下    | -8.3  | -5.2  |  1.8  |  0.0  
| 左    |  1.8  |  2.1  |  4.5  |  7.2
| 右    |  6.2  |  8.0  | 10.0  |  0.0
+-------+-------+-------+-------+
```

#### 最终策略

```
最优策略π*：
(0,0) → 右 (Q=6.2，最大)
(0,1) → 右 (Q=8.0，最大)  
(0,2) → 右 (Q=10.0，最大)

最优路径：(0,0)→右→(0,1)→右→(0,2)→右→(0,3)
```



## Q-Learning

核心：贝尔曼Bellman方程

$Q(s,a)←Q(s,a)+\alpha(r+\gamma max_{a'}Q(s',a')-Q(s,a))$

其中$\alpha$是学习率，$\gamma$是折扣因子



### 具体流程

假设$\alpha = 0.5, \gamma=0.9$

1. 初始化Q表（默认全为0）。从某一状态$s_0$开始

2. 根据策略选择要执行的动作$a_0$（对于刚开始，大概率是随机策略）

现在选择了$a_0$，假设到了$s_1$，收获奖励$r_1=+5$

3. 更新Q值

$Q(s_0, a_0) = Q(s_0,a_0)+\alpha(r+\gamma max_{a'}Q(s',a')-Q(s,a))=0+0.5*(5+0.9*0-0)=2.5$

4. 现在所处的状态变成$s_1$了，继续执行2-3步



### 可选的不同种类替代

#### 探索 vs 利用

体现在”根据策略选择要执行的动作$a_0$“步骤。可以采用$\epsilon-greedy$等方法，要执行的下一步动作可以不是Q值最大的



## On-Policy vs Off-policy

**On - Policy：**

学什么策略，就用什么策略生成经验。**所采集的数据**必须来自当前**正在学习的策略**。

例如：

- 蒙特卡洛评估：针对一个**给定的策略 π**，使用由**该策略 π 生成的路径**来学习其每个状态的Q值或V值，从而评估这个策略 π 的好坏。
- 蒙特卡洛控制（标准版）/ SARSA：不断学习再优化自身（当前执行的策略），以趋于使Return最大的策略。

**Off-Policy：**

学习的策略是一个目标策略，目标策略和用户收集数据的行为策略可以不同。在学习过程中，所使用的策略与实际执行策略不一致。也就是说，Off-Policy算法学习的**目标策略的价值或其本身的最优性，不被行为策略的价值或最优性所限制**，但学习过程仍然**依赖行为策略提供足够有覆盖性的经验数据**。

例如：

- Q-Learning，采样时可以采用$\epsilon-greedy$等策略，也可以通过一些别的策略采样而来（甚至可以是历史数据），但（假设数据足够多）最终都会趋于学习到使Return最大的策略（完全的贪心）。



## DQN

思想：对于复杂的场景（比如游戏，每一帧都不完全一样，不是完全相同的状态），(s,a)元组的数量会特别多，无法使用表来穷举。这时候需要有一个相对软的策略来计算Q(s,a)，采用一个以(s,a)为输入的深度神经网络，计算Q值

### 具体流程

组成：

- 一个主网络（训练的最终目标，过程中选择动作、计算预测Q值）
- 一个目标网络（训练过程中的辅助，用来生成目标Q值，即要优化达到的“目标”）
- 一个经验回放缓冲区，有一个最大长度$N_{buffer}$，存放$(s,a,s',r)$经验，若满则最旧的经验移出

过程：

1. **初始化阶段**

初始化经验回放缓冲区$D$、主网络$Q$的参数$\theta$，目标网络$\hat{Q}$的参数$\theta'=\theta$

2. **主训练循环**

$for\ t\ from\ 1\ to\ T_{episode}$，对每一个循环，执行如下步骤：

- **状态预处理：**对于当前状态$s_t$，预处理后得到网络输入$\phi_t$
- **选择动作：**在**主网络**中，使用$\epsilon-greedy$策略选择要执行的动作$a_t$。这里非$\epsilon$随机选择的情况下选择$a_t=argmax_aQ(s_t,a,\theta)$。这里$\epsilon$的值应该是随着t变大（探索逐渐完成）而衰减的。例如，开始时$\epsilon=1$（完全探索），后期到很小的值如0.01或0.1
- **执行动作，收集结果：**在环境中执行动作$a_t$，得到奖励$r_t$和下一个状态$s_{t+1}$

- **结果放入缓冲区：**将经验元组$(\phi_t,a_t,r_t,\phi_{t+1})$放入经验回放缓冲区$D$（当然，如果已满，清除掉最旧的经验）
- **取小批量：**从经验回放缓冲区中随机取$K$个数据$(\phi_j,a_j,r_j,\phi_{j+1})$**（这个步骤每个循环都要做！！！每一轮都要更新主网络）**

- **计算目标Q值：**对$(\phi_j,a_j,r_j;\phi_{j+1})$，若$\phi_{j+1}$为终止状态，目标Q值$y_j=r_j$；若不是终止状态，目标Q值$y_j=r_j+\gamma max_{a'}\hat{Q}(s_j,a_j;\theta')$（这里是从**目标网络**里取的Q值）

- **计算损失，更新主网络参数：**$L=\frac{1}{K}\sum_j(y_j-Q(\phi_j,a_j;\theta))^2$
- **更新参数：**反向传播对主网络$Q$进行参数更新
- **更新目标网络：**每隔$C$个时间步，$\theta'←\theta$（将主网络参数同步到目标网络）
- **状态转移：**将当前状态置为$s_{t+1}$，继续循环

3. **当达到循环结束条件（例如达到足够时间步，或性能基本不变），停止循环**



### 一个误区及ChatGPT的回答：

- 目标网络一开始也很差，为什么还能作为训练目标使用？

虽然目标网络在初期确实不准，**但它和主网络一样，是从零开始慢慢学起来的**，它的目标值不需要“完美”，只要能提供**相对稳定、略微有方向性的信号**就足够了。

**🔁 更详细地说：**

**🎯 目标网络并不是“完美标签”，它只是“软标签”**

在监督学习中，我们有“正确答案”当标签；但在强化学习中，我们没有。我们自己生成标签：

- 我们用网络自己估计未来的价值（**Bootstrap** 方法）
- 这个估计当然不是完美的，它的准确性会随训练逐步提升

**目标网络提供的是一种“稳定但不完美的估计”**

即使早期估计不准，它仍然能提供：

- **方向感**：哪些动作带来高回报
- **更新信号**：让主网络学到“当前认为最好的策略”
