# Attention - 合集

## Attention解决什么问题？

序列模型如RNN/LSTM等，

1. 对长期记忆有遗忘的问题
2. 对输入序列的每个部分给予同样的关注

Attention解决这两个问题，对相对重要的token给予更多关注，且能看到整个序列，不会遗忘





## 基础款：单头Attention

已有Q向量，和一个长度为n序列的K，V向量

1. Q与序列（长度为n）中所有K做点积，得到n个值
2. 归一化：每个值除以$\sqrt{d_k}$，送入softmax，得到新的n个值
3. 使用这n个值乘以对应的V向量，得到加权和

单头Attention的问题：只能从一个“角度”或“表示子空间”去学习关注点



## 进阶：多头Attention（MHA，Multi-Head Attention）

单头Attention的改进，可以学到更多角度的信息

已有Q向量，和一个长度为n序列的K，V向量。设注意力头数是h

1. 原始的Q，K，V分别输入h个$W_Q^i,W_K^i,W_V^i$，拆成h组$Q_i, K_i, V_i$
2. 对每组$Q_i, K_i, V_i$分别算一个单头注意力，得到输出$O_i$
3. 所有输出$O_i$拼接到一起，再乘以$W_O$，输出出最终向量



## Decoder专属：掩码自注意力机制

在常规注意力的基础上，在softmax前对masked的部分减去无穷大，这样softmax后的值就接近0



## 轻量版：MQA（Multi-Query Attention）

所有的K，V向量只做成单头，但当前要用的Q向量使用$W_Q^i$给拆成多头。也像MHA一样计算多个头的输出，最终合并再经过$W_O$得到最终结果

性能相较MHA有所下降，但节省了大量KV Cache的缓存



## 轻量版2：GQA（Grouped-Query Attention）

K，V向量用权重矩阵做成m头，Q向量做成n头（n=km，k是整数），一个KV对应多个Q。我们当前的$Q_i$需要找到对应那组$K_j, V_j$，来计算最终输出。也像MHA一样计算多个头的输出，最终合并再经过$W_O$得到最终结果



## MHA，MQA，GQA举例对比

MHA：所有的K，V都8头，当前要用的Q也是8头，Q与KV一一对应，最后得到的8个输出向量合并、经过$W_O$输出

MQA：所有的K，V都1头，当前要用的Q是8头，每个Q的头都和KV一一作用，最后得到的8个输出向量合并、经过$W_O$输出

GQA：所有的K，V都2头，当前要用的Q是8头，Q的1-4头和第一组KV相作用，Q的5-8头与第二组KV相作用，最后得到的8个输出向量合并、经过$W_O$输出



## DCA：Dual Chunk Attention 长序列推理优化

核心思想：在预训练最大长度一定时，通过分块来调整不同距离的Q和K之间的相对距离计算方式，来实现推理时超过预训练最大长度的文本处理。只改变了相对位置的计算（影响RoPE位置编码），没有改变Attention的计算方式

假设预训练支持的最大长度为c，我们要把文本切分为长为s的chunk，w是超参数

思路：

1. 将整个文本序列按照chunk_size = s来切分

2. 对每个chunk里的所有k，按照位置=它在当前chunk里的位置来决定它计算时的位置$P_k$。$P_k[i] = i\ mod\ s$。例如第2个chunk的第0个k的$P_k=0$，而第3个chunk的第7个k的$P_k=7$

3. 对我们要用的q向量，分以下三种情况讨论，来计算它与某个地方的k的相对位置距离
   - （块内注意力）如果k与q位于同一chunk，p的位置$P_p$就是它在当前chunk内的位置$i$。一个chunk内所有$P_{p_i}$形如$[0,1,2,3,...,s-1]$
   
   - （相邻块注意力）如果k在q前一个chunk，p的位置$P_p$在chunk内：对于一个chunk内的所有$P_{p_i}$，形如$[s,s+1,...s+w-1,c-1,c-1,...,c-1]$

     `w` 的推荐设置：`w` 可以直接设为**预训练长度 `c` 和块大小 `s` 的差值 (`w = c - s`)** 。
   
   - （块间注意力）如果k在q的前一个chunk再之前的位置，那么对于一个chunk的所有$P_{p_i}$，形如$[c-1,c-1,...,c-1]$
   
4. 使用上述的p向量的位置编码规则来计算p与k的相对位置关系，加上相对位置编码RoPE

直观理解：通过这样的位置分配，对于我们的p，离的近的k（和p同一个chunk内的k，或上一个chunk里偏后的k）我们的p与k的位置计算是比较精确的；而对于离得远的k，我们的p的位置直接写成c-1（预训练最大长度），表示离k很远，且同一个chunk内的k和p的相对位置也不一样，能建模这种先后关系

结果证明，这种方法不会使生成回答的质量降低太多（困惑度只降了一点点），却能以同样的训练成本和预训练最大长度，生成长的多的回答。同时它也能无缝支持Flash Attention2。如果不用DCA，直接让模型生成比预训练文本长的内容，效果不好。
