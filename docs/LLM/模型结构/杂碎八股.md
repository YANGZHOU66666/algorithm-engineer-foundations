# Transformer杂碎八股

- $q·k$为什么除以$\sqrt{d_k}$

把点积结果从均值为0、方差为$d_k$的分布，映射到均值为0、方差为1的分布中；防止注意力得分之间的分布过于陡峭，softmax梯度小，梯度消失

证明：

对于q、k向量的每个位置$q_i,k_i$，理论上方差为1、均值为0

对于$q·k=\Sigma_{i=0}^{d_k}q_i·k_i$，均值为0、方差为$d_k$。因为：

$$ \mathbb{E}[q_i k_i] = \mathbb{E}[q_i] \cdot \mathbb{E}[k_i] = 0 \times 0 = 0 $$

$$ \text{Var}(q_i k_i) = \mathbb{E}[(q_i k_i)^2] - (\mathbb{E}[q_i k_i])^2 $$，而$\mathbb{E}[q_i k_i] = 0$，因此$$ \text{Var}(q_i k_i) = \mathbb{E}[q_i^2 k_i^2] $$；而由于$$ \text{Var}(q_i) = \mathbb{E}[q_i^2] - (\mathbb{E}[q_i])^2 $$，已知 $\text{Var}(q_i) = 1$，$\mathbb{E}[q_i] = 0$，代入得：$$ 1 = \mathbb{E}[q_i^2] - 0^2 \implies \mathbb{E}[q_i^2] = 1 $$，同理，$\mathbb{E}[k_i^2] = 1$。因此$$ \text{Var}(q_i k_i) = 1 \times 1 = 1 $$



- 为什么LayerNorm而不是BatchNorm？

LayerNorm：在特征向量内部做归一化；BatchNorm：在一个batch内，对不同特征向量相同维度上归一化

1. NLP任务不同序列不一样长，一个batch内有的序列已经padding，padding和正常字符一起归一化，导致均值、方差和想要的分布不一样。（BatchNorm 隐含假设：**同一时间步t上，所有 batch 样本的值都是有意义的、同分布的**。）
2. LLM训练显存开销大， 很多时候batch_size设置的小，导致不同位置归一化结果波动大（有时候值很大，有时候值很小），训练不稳定
3. batch_norm在训练时还会维护这个位置上整体的均值和方差，但对于NLP任务，batch内部序列长度不一样时不同位置的均值和方差完全不一样（batch_norm想维护的：特征向量某一位上的值，在整个数据集上的分布情况；但transformer这种类型，由于句子长短/不同token在句子中的位置不同，向量在某一位上的值分布差异比较大）
