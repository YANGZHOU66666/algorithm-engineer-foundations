# LLM通识

## Scaling Law

模型的效果随参数量、训练数据的增加而变好

$$ L(N, D, C) \approx \left( \frac{N_c}{N} \right)^\alpha + \left( \frac{D_c}{D} \right)^\beta + E $$

N：模型参数量

D：训练数据量

E：常量，即便参数量、数据量拉满也固有的损失值

$N_c, D_c, \alpha, \beta$：由大量经验数据总结出的常量



## temperature, Top-k, Top-p含义

都是用来控制“更有创意、更多变”还是“更稳妥、更可靠”的超参数

- temperature：对logits做的放缩。

公式：$softmax(\frac{logits}{temperature})$，当temperature比较大时，所有概率输出相对差距不会太大；当temperature比较小时，所有概率输出相对差距会很大。

理论上temperature=0时，变成贪心策略采样。



- Top-k：采概率前几个的问题

直接从排行榜上选出概率Top的前k个词，组成候选集合

比如说，next token有如下几个词和概率：

| 散步 | 休息 | 跑步 | 玩   | 野餐 |
| ---- | ---- | ---- | ---- | ---- |
| 0.8  | 0.1  | 0.05 | 0.02 | 0.01 |

假如k=2，就会在“散步”和“休息”中按照8：1的概率抽样，其他的概率为0



- Top-p：采前多少概率的问题

按照概率从高到低排列，依次加起来，直到累积概率达到p，把这部分作为候选集合

比如说，next token有如下几个词和概率：

| 散步 | 休息 | 跑步 | 玩   | 野餐 |
| ---- | ---- | ---- | ---- | ---- |
| 0.8  | 0.1  | 0.05 | 0.02 | 0.01 |

假如p=0.95，就会在“散步”“休息”和“跑步”中按照概率比来抽样，其他的概率为0



## 预训练, SFT, RLHF作用

预训练：学习通用知识，获得通用能力

SFT：指令遵循（理解指令）能力，输出格式对齐的能力，领域知识注入（事实性对齐），风格模仿

RLHF：使用奖励模型建模人类偏好。对齐人类偏好，如何让模型的回答更有用、更诚实、更无害？复杂推理任务，尤其是数学和代码等
