# LLM预训练 Pretrain

## 基本方法

预训练两种含义：

1. 从0开始，随机初始化所有参数
2. 开源已经预训练好的基础上，针对特定行业加强训练，提升通用模型的领域知识和能力



预训练语料：“今天天气不错。”

假设分词分为：`今天`，`天气`，`不错`，`。`

最开始输入“今天”，预测下一个token，需要让“天气”的概率尽可能大，其他token的概率尽可能小

![](./assets/预训练-预测下一个token.png)

同理，输入“今天 天气”，要让预测下一个token为“不错”的概率尽可能大，其他的概率尽可能小

后面的以此类推

对于最后的输入“今天天气不错。”，丢弃预测的下一个token，不对其进行loss计算

对输出结果当作分类问题来算，使用Cross Entropy Loss，预测结果是每个token的概率分布，标签就是句子的每一个token

## 8.15 补充：纠正一些错误理解

取一个max_seq_len的数据（如上文["BOS", "今天", "天气", "不错"]），使用$W_Q,W_K,W_V$计算每个token的Q、K、V向量。注意！首先用"BOS"的Q查["BOS"]的K、V，预测的下一个token与"今天"算loss；然后用"天气"的Q查["BOS", "今天"]的K、V，预测的下一个token与"天气"计算loss。

关键点：

1. 第i个token的Q只可能与它自己和它之前序列的K、V来算（也就是因果masked机制），预测下一个token
1. 每个max_seq_len长度的序列为一组（这是通常的做法，即所训练大模型的最长上下文长度），可以直接先计算整个序列的QKV，但具体预测某个token时决定用不用。这样可以复用大量K、V向量。（之前的错误认知：构造一系列{"input":seq, "label":next token}的数据，但只用这个seq预测下一个token，这样每次都要计算一个序列的所有K、V向量，浪费）
