# 对比PPO, DPO, GRPO

## PPO

四个模型：参考模型、正在训练的模型、状态价值模型、奖励模型

不需要标注好的数据

优点：

- 准确？
- 不需要标注数据，只需要换奖励模型/函数，灵活性好

缺点：

- 显存占用最大；速度慢



## DPO

两个模型：参考模型，正在训练的模型

必须要标注好的正负样本对，由于奖励值和模型最优参数之间满足定量关系，可以直接通过最大化正负样本得分之差来直接优化模型参数

优点：

- 显存占用最小

缺点：

- 必须要有标注的正负样本对
- 可能会过拟合样本，不如用奖励模型的泛化性好



## GRPO

三个模型：参考模型，正在训练的模型，奖励模型

对每个prompt采样n条回答，组内归一化奖励得分

优点：

- 显存占用比PPO小

缺点：

- 几个xxPO要优化的点就是缺点？
